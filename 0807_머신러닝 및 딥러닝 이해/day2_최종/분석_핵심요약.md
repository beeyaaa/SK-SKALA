# Day 2 분석 핵심 요약 — 견해와 선택 근거

Adult(1994 US Census) 데이터, 결혼 경험 여부에 따른 평균 교육연수(`education-num`) 차이
상세 근거는 [분석_종합_리뷰.md](분석_종합_리뷰.md) 참조

## 1. 결론 세 줄

1. 평균 차이는 `+0.174년`으로 **통계적으로는 유의하지만(p=2.6×10⁻⁹) 실질적으로는 무의미**하다. 효과크기 g=`0.068`, 두 집단 중앙값은 모두 10년.
2. 나이·성별을 보정하면 `-0.365년`으로 **부호가 반전된다.** 두 집단의 평균 나이가 `15.5세`나 다르기 때문. **이 부호 반전이 이 분석의 진짜 발견이다.**
3. 분류 모델(정확도 `0.8228`)은 `age` 하나만 써도 `0.8095`가 나온다. **사실상 나이 모델**이다.

> 즉 이 분석의 답은 "결혼 경험에 따라 교육연수가 다르다"가 아니라, **연령 구성이 극단적으로 다른 두 집단을 단순 비교해서는 이 질문에 답할 수 없다**는 것이다.

## 3. 왜 이 전처리를 했는가

| 전처리 | 핵심 근거 |
|---|---|
| `?` → 결측 변환 | 안 하면 모델이 `?`를 **정상 범주로 학습**한다 |
| 문자열 공백 제거 | 공백 차이만으로 같은 범주가 둘로 갈라져 One-Hot 열이 중복 생성된다 |
| 완전 중복 24행 제거 (**분할 전**) | 같은 행이 Train/Test에 나뉘면 이미 본 행을 맞히며 성능이 부풀려진다 |
| 결혼 경험 이진 재분류 | 통계 검정의 집단과 ML 타깃을 **같은 개념**으로 맞춰야 두 분석을 함께 해석할 수 있다 |
| 결측 대치를 **분할 후 Pipeline 안**에서 | 전체 데이터로 중앙값을 구하면 Test 정보가 Train으로 새는 **누수**가 된다 |
| 중앙값 대치 | `capital-gain`처럼 치우친 변수에서 평균 대치는 이상치에 끌려간다 |
| StandardScaler | `age`(17~90)와 `capital-gain`(0~99,999)의 스케일 차가 약 1,000배 |
| One-Hot Encoding | `occupation`·`race`는 명목형. 레이블 인코딩은 **없는 크기 순서**를 만든다 |
| `marital-status`·`relationship` 제외 | 전자는 **타깃을 만든 원본 변수**, 후자는 `Husband`/`Wife`로 혼인 상태를 그대로 드러내는 대리변수 |
| `fnlwgt` Feature 제외 | 개인 속성이 아니라 **표본 추출 가중치**다 |

## 5. 통계·모델 선택 근거

| 선택 | 왜 |
|---|---|
| **Welch t-test** | Levene p=`5.22×10⁻³²`로 등분산이 명확히 기각. 표본 수도 2배 차이. 이 조건에서 Student t는 1종 오류율이 왜곡됨 |
| **Hedges g 병행** | p-value는 표본 크기에 좌우된다. 32,537개면 무의미한 차이도 유의해진다 |
| **OLS 보정** | 두 집단 나이가 15.5세 차이. 그대로 비교하면 결혼 경험이 아니라 **연령 차이를 재는 것** |
| 나이² 포함 | 교육연수-나이 관계는 단조가 아님(세대별 교육 확대) |
| 나이 표준화 | 원척도 제곱은 90²=8100으로 커져 수치 불안정 |
| **HC3 강건 SE** | 이산 종속변수라 잔차 이분산이 확실 |
| Logistic Regression | 이진 분류 baseline이고 계수 해석이 가능 |
| 계층화 분할 | 양성 67% 데이터를 무작위로 나누면 fold별 비율이 흔들림 |
| Mann–Whitney | 보조 확인용. **평균 검정이 아니므로 Welch 대체로 쓰면 안 됨** |

## 6. 개인 인사이트

### ① 분석이 틀린 줄 알았던 지점이 사실은 결론이었다

보정 후 부호가 뒤집혔을 때 처음 든 생각은 "코드가 잘못됐다"였다. 그런데 두 집단의 평균 나이를 확인하니 `28.15세` vs `43.68세`, **15.5세 차이**였다. 반전은 버그가 아니라 데이터가 보내는 신호였다.

**교과서에서 심슨의 역설을 읽는 것과, 내 결과가 뒤집히는 걸 보는 건 전혀 다른 경험이었다.** 결과가 예상과 다를 때 그걸 고쳐야 할 오류로 볼지 설명해야 할 현상으로 볼지가 분석의 갈림길이라는 걸 배웠다.

### ② p-value가 작다는 건 자랑이 아니라 경고였다

p=`2.6×10⁻⁹`을 처음 봤을 때는 "강한 결과"로 읽었다. 하지만 표본이 32,537개면 **아무리 작은 차이도 유의해진다.** 실제 차이 `0.174년`은 표준편차 `2.4~2.7년`의 1/15이고 두 집단 중앙값은 똑같이 10년이다.

효과크기를 같이 계산하지 않았다면 "결혼 경험에 따라 교육 수준이 유의하게 다르다"고 썼을 것이다. **틀린 문장은 아니지만 독자를 완전히 잘못된 인상으로 이끄는 문장이다.**

### ③ 이 데이터가 실제로 보여주는 건 결혼이 아니라 '20세기 교육 확대'다

부호 반전의 원인을 추적하면서 나이가 두 방향으로 동시에 작용한다는 걸 알았다.

- 나이 ↑ → 결혼을 경험할 **시간**이 길다 (기계적 관계)
- 나이 ↑ → 1994년 기준으로 젊은 시절 **교육 기회가 적었다** (세대 효과)

비보정 차이 `+0.174년`은 이 반대 방향 두 힘이 상쇄되고 남은 잔여물이다. 즉 **내가 재고 있던 건 결혼과 교육의 관계가 아니라, 데이터에 각인된 미국 교육 확대의 역사였다.** 1994년이라는 수집 시점이 결과를 지배한다는 걸 체감했다.

### ④ 정확도 `0.8228`은 모델이 아니라 '나이'의 성적이었다

| 모델 | 정확도 | Macro F1 |
|---|---:|---:|
| 전체 11개 Feature | 0.8228 | 0.7966 |
| **`age` 하나만** | **0.8095** | **0.7789** |
| `age` 제외 | 0.7097 | 0.6338 |
| 기준모델(항상 "있음") | 0.6722 | 0.4020 |

나머지 10개 변수가 더하는 값은 **정확도 `+1.3%p`** 뿐이었다. 성능 숫자만 보고했다면 "쓸 만한 모델"로 넘어갔을 것이다.

**성능이 얼마인가보다 그 성능이 어디서 왔는가가 중요하다.** 이 모델이 학습한 건 "나이가 많으면 결혼을 경험했을 것"이라는 거의 동어반복이고, 기준모델과 `age`-only를 같은 표에 올려야만 그게 보인다.

### ⑤ 데이터 누수는 O/X가 아니라 스펙트럼이었다

`marital-status`는 타깃을 만든 변수니 빼는 게 당연했다. 문제는 그다음이었다.

| 변수 | 성격 | 판단 |
|---|---|---|
| `marital-status` | 타깃 생성 원본 | 명백한 누수 → 제외 |
| `relationship` | `Husband`/`Wife`로 상태가 드러남 | 강한 대리변수 → 제외 |
| `age` | 결혼할 시간의 양 | 부분 대리변수 → 유지 |
| `income`·`hours-per-week` | 결혼 **이후** 결정 가능 | 사후 변수 → 목적에 따라 |

어디서 끊어야 할지 정답이 없었다. 결국 **분석 목적이 경계를 정한다**는 결론에 도달했다. 순수 예측이면 다 넣어도 되지만, 해석이 목적이면 사후 변수를 잘라야 한다. 실제로 잘라봤더니 정확도는 `0.8228→0.8119`로 거의 안 떨어졌다 — **해석 가능성을 크게 얻고 성능은 거의 안 잃는 교환**이었다.

### ⑥ 전처리의 대부분은 성능이 아니라 '정직함'을 위한 것이었다

처음엔 전처리를 성능 향상 작업으로 생각했다. 실제로는 반대였다.

- 문자열 공백 제거 `455,854건` → 성능 변화 없음
- 중복 24행 제거 → 평균 차이 `0.176 → 0.174`, 결론 동일
- `fnlwgt` 가중 → `0.172`, 결론 동일

**전부 결과를 바꾸지 않았다.** 그런데도 해야 하는 이유는, 안 하면 "그것 때문에 결과가 이런 것 아니냐"는 질문에 답할 수 없기 때문이다. 전처리는 성능 최적화가 아니라 **반박 가능성을 미리 제거하는 작업**이라는 걸 알았다.

### ⑦ 같은 노트북에 있다고 같은 결론을 지지하는 게 아니다

Welch t-test는 "두 집단의 평균이 다른가"를, 로지스틱 회귀는 "두 집단을 구분할 수 있는가"를 묻는다. **다른 질문이다.** 평균 차이는 `0.174년`으로 무시할 만한데 분류 정확도는 `0.8228`로 높다 — 모순이 아니라 애초에 다른 걸 재고 있어서다.

처음엔 ML 결과가 통계 결과를 뒷받침한다고 생각했다. 두 분석을 나란히 놓을 때 **각각이 답하는 질문을 먼저 구분해야 한다**는 걸 배웠다.

## 8. 최종 결론 문장

> 1994년 Adult 표본에서 결혼 경험이 있는 집단의 평균 교육연수는 없는 집단보다 `0.174년` 높았고 통계적으로 유의했다(p=`2.6×10⁻⁹`). 그러나 효과크기는 `0.068`로 매우 작고 두 집단 중앙값은 모두 10년이어서 실질적 교육 격차로 보기 어렵다. 나이·성별을 보정하면 차이가 `-0.365년`으로 **반전**되는데, 두 집단의 평균 나이가 `15.5세` 다르기 때문이다. 따라서 이 결과는 결혼 경험의 인과효과가 아니라 **연령 구성 차이가 만들어낸 관찰상의 연관성**으로 해석해야 한다. 분류 모델 또한 `age` 단일 변수로 대부분의 성능이 재현되므로, 미래의 결혼 여부나 결혼의 원인을 예측하지 않는다.
