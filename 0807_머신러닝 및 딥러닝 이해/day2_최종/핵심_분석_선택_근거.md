# 결혼 경험과 교육수준 코드 분석: 핵심 견해와 선택 근거

## 1. 핵심 결과와 나의 견해

- 결혼 경험 없음 집단: `10,667명`, 평균 교육수준 코드 `9.965`
- 결혼 경험 있음 집단: `21,870명`, 평균 교육수준 코드 `10.139`
- 비보정 평균 차이: `+0.174점`
- Welch 95% CI: `[0.117, 0.231]`
- p-value: `2.648×10⁻⁹`
- Hedges g: `0.068`, 매우 작은 효과

귀무가설은 기각되지만 두 집단의 중앙값은 모두 `10`이고 효과크기도 매우 작다. 따라서 나는 이 결과를 **통계적으로는 유의하지만 실질적인 교육 격차는 크지 않은 결과**로 해석한다. `education-num`은 실제 교육기간이 아니라 학력 범주에 대응된 순서형 코드이므로 `0.174점`을 연수나 개월 수로 환산해서는 안 된다.

나이·성별을 보정한 OLS에서는 차이가 `-0.365점`으로 반전됐다. 결혼 경험 있음 집단의 평균 나이는 `43.68세`, 없음 집단은 `28.15세`로 약 `15.5세` 차이가 난다. 따라서 비보정 결과에는 결혼 경험뿐 아니라 연령·출생 코호트 구성 차이가 크게 섞여 있다고 판단한다.

## 2. 핵심 전처리 선택 근거

| 선택 | 수행 내용 | 선택 이유와 판단 |
|---|---|---|
| 문자열 정리 | 공백 제거, `?`를 결측치로 변환 | 같은 범주의 표기 차이를 없애고 결측 처리가 가능하도록 함 |
| 결혼 경험 재분류 | Never-married=없음, 기혼·이혼·별거·사별=있음 | 연구가설의 두 비교집단을 명확하게 정의 |
| 완전 중복 제거 | 24행 제거 | 동일 관측치의 반복이 집단 통계와 검정에 중복 반영되는 것을 막기 위해 제거. 다만 개인 ID가 없어 실제 중복인지는 불확실하며, 유지해도 평균 차이는 `0.176점`으로 결론이 거의 같음 |
| 핵심 변수 결측 처리 | 교육수준 코드·나이·성별·혼인 상태 완전사례 사용 | 네 변수의 결측이 실제로 0개라 분석 표본 손실 없음 |

### 적용하지 않은 전처리

| 미적용 항목 | 미적용 판단 |
|---|---|
| IQR 제거·clip | 극단값이 실제 Census 응답일 수 있고, 행 제거 시 원표본 평균이라는 분석 대상이 바뀜. 다만 최종본에는 IQR·도메인 감사 근거가 부족함 |
| 교육수준 코드 로그 변환 | `1~16`의 순서형 코드로, 로그 변환한 값의 교육적 의미가 명확하지 않아 미적용 |
| 연령·교육수준 구간화 | 임의 경계와 정보 손실을 피하고 연속값·나이²를 사용 |
| `fnlwgt` 가중 추론 | 최종 분석은 비가중 표본 차이를 사용. 가중 평균 차이는 약 `+0.172점`으로 방향은 같지만 조사설계 추론은 미수행 |

## 3. EDA 선택 근거

### 수행한 EDA

| EDA | 수행 이유 | 확인한 내용 |
|---|---|---|
| 결측·중복·범위 점검 | 분석 가능한 표본 확정 | 32,561행, 결측 4,262개, 중복 24행 |
| 혼인 상태 구성 | 이진 집단 정의 검증 | 결혼 경험 있음 집단의 내부 구성이 이질적임 |
| 평균·중앙값·표준편차 | p-value 이전에 실제 차이 확인 | 평균은 0.174점 차이지만 중앙값은 동일 |
| 히스토그램·violin·boxplot·ECDF | 전체 분포와 겹침 확인 | 교육수준 코드는 이산적이고 두 집단 분포가 크게 겹침 |
| Levene·Q-Q plot | Welch 선택과 분포 형태 점검 | 분산이 다르고 완전한 정규분포는 아니지만 표본이 큼 |
| 비보정·보정 CI 비교 | 공변량 보정의 영향 확인 | 결과가 `+0.174점→-0.365점`으로 반전 |
| 2,000회 부트스트랩 | 평균 차이 CI의 강건성 확인 | CI `[0.115, 0.232]`로 Welch와 유사 |

### 추가했으면 좋은 EDA

- 집단별 나이 분포와 성별 비율: 보정 후 부호 반전을 직접 설명
- 연령별 교육수준 코드 차이: 결혼 경험과 교육수준의 연관성이 나이에 따라 달라지는지 확인
- 기혼·이혼·별거·사별 세부집단 비교: 결혼 경험 있음 집단의 이질성 확인
- `fnlwgt` 가중·비가중 비교와 중복 유지·제거 민감도

## 4. 통계·모델 선택 근거

| 선택 | 사용 이유 | 핵심 한계 |
|---|---|---|
| Welch t-test | 표본 수와 분산이 다른 독립 두 집단의 평균 비교 | 표본 독립성과 조사설계 가정이 남음 |
| 양측검정·α=0.05 | 차이의 방향을 미리 단정하지 않고 검정 | 큰 표본에서는 작은 차이도 유의해 효과크기 병행 필요 |
| Hedges g | p-value와 별개로 실제 차이의 크기 평가 | 실질적으로 중요한 기준을 사전에 정하지 않음 |
| Bootstrap | Welch CI가 분포 가정에 과도하게 의존하는지 확인 | 반복 수에 따른 Monte Carlo 오차 미표시 |
| Mann–Whitney U | 분포·순위 차이 보조 확인 | 평균 차이 검정이 아니므로 Welch 대체로 해석하면 안 됨 |
| OLS+HC3 | 나이·성별 보정 평균 차이와 이분산 강건 CI 계산 | 인과모델이 아니며 미측정 교란이 남음 |
| 나이+나이² | 교육수준 코드와 나이의 비선형 관계 반영 | 결혼 경험×나이 상호작용은 빠져 있음 |

## 5. 핵심 인사이트

1. **통계적 유의성과 실질적 중요성은 다르다.** p-value는 매우 작지만 효과크기는 `0.068`이다.
2. **가장 중요한 결과는 부호 반전이다.** 비보정과 보정 결과가 반대라는 것은 연령·세대 구성이 강하게 섞여 있다는 뜻이다.
3. **보정 결과도 인과효과가 아니다.** 결혼 시점, 교육 완료 시점, 가족 배경 등 중요한 정보가 없다.
4. **`education-num`은 실제 교육연수가 아니다.** 결혼 경험과 교육수준 코드의 대략적인 연관성은 확인할 수 있지만 실제 교육기간의 차이로 해석할 수 없다.

## 6. 주요 한계와 보완점

| 한계 | 보완 방향 |
|---|---|
| 단면자료라 시간 순서·인과관계 확인 불가 | 결혼 시점·교육 완료 시점이 있는 종단자료 사용 |
| 결혼 경험 있음 집단이 이질적 | 기혼·이혼·별거·사별을 분리해 비교하고 다중비교 보정 |
| 나이·성별만 보정 | DAG를 먼저 정의하고 인종·출신 국가 등 사전 교란변수 검토 |
| 연령별 집단 차이를 일정하게 가정 | 결혼 경험×나이 상호작용 또는 spline과 평균 표준화 사용 |
| 교육수준 측정의 제한 | `education-num`은 실제 교육기간이 아닌 순서형 코드이므로 원래 교육 범주의 분포, Mann–Whitney U, 순서형 회귀를 민감도로 추가 |
| 비가중 분석 | `fnlwgt` 가중 결과와 조사설계 한계를 함께 제시 |
| 이전 산출물 명칭 혼재 | `adult_income_*` 파일을 `legacy/`로 분리하거나 최종본에서 제외 |

## 7. 최종 결론

> Adult Census 표본에서 결혼 경험 있음 집단의 평균 교육수준 코드는 없음 집단보다 약 `0.174점` 높았고 통계적으로 유의했다. 그러나 효과크기는 `0.068`로 매우 작았고 두 집단의 중앙값도 모두 `10`이었다. 나이와 성별을 보정하면 차이가 약 `-0.365점`으로 반전되어, 비보정 결과에 연령·출생 코호트 구성 차이가 크게 섞여 있음을 확인했다. 따라서 이 결과는 결혼 경험의 인과효과가 아니라 1994년 Adult 표본에서 관찰된 연관성으로 해석해야 한다. 또한 `education-num`은 실제 교육기간이 아닌 순서형 코드이므로 연수나 개월 수로 환산할 수 없다.
