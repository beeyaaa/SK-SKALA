## 1. 비보정 집단 차이는 유의했지만 실질적 크기는 매우 작음

- 결혼 경험 없음 집단
  - 표본: `10,667명`
  - 평균 교육수준 코드: `9.965`
- 결혼 경험 있음 집단
  - 표본: `21,870명`
  - 평균 교육수준 코드: `10.139`
- Welch t-test
  - 비보정 평균 차이: `+0.174점` (`있음−없음`)
  - p-value: `2.648×10⁻⁹`
  - 95% 신뢰구간: `[0.117, 0.231]`
  - 신뢰구간이 `0`을 포함하지 않아 평균 코드가 같다는 귀무가설 기각
- 실질적 차이
  - Hedges' g: `0.068`
  - 두 집단의 중앙값: 모두 `10`
  - 통계적으로 유의하지만 현실적인 집단 차이는 매우 작다고 판단
- 강건성 확인
  - 부트스트랩 95% 신뢰구간: `[0.115, 0.232]`
  - Mann–Whitney U에서도 순위 분포 차이 확인
  - Mann–Whitney U는 평균 차이 검정이 아니므로 보조 결과로만 해석
- 해석 범위
  - Welch t-test는 표본 수와 분산 차이를 반영한 비보정 평균 비교
  - 연령·성별 등 집단 구성 차이와 인과관계는 설명하지 못함
  - `education-num`은 순서형 코드이므로 등간격을 가정한 평균 비교라는 한계가 있음

## 2. 나이·성별 보정 후 집단 차이의 방향이 반전됨

- OLS 보정변수: 나이·나이²·성별
- 보정 후 결혼 경험 집단 간 차이: `-0.365점`
- 보정 전후 변화: `+0.174점 → -0.365점`
- 집단별 평균 나이
  - 결혼 경험 있음: `43.68세`
  - 결혼 경험 없음: `28.15세`
  - 집단 차이: 약 `15.5세`
- 해석
  - 단순 평균 차이에 연령 구성의 영향이 섞여 있었음을 보여줌
  - 1994년 단면자료에서 연령은 출생 세대와 연결되지만 출생 세대의 영향은 직접 검정하지 않음
  - 이번 분석에서는 중복 제거·가중치보다 보정변수 적용이 결과에 더 큰 변화를 만듦
  - 보정 결과도 제한된 변수에 조건화한 연관성이며 인과효과는 아님

## 3. EDA를 근거로 불필요한 전처리와 데이터 손실을 피함

- 핵심 변수 결측치
  - 교육수준 코드·나이·성별·혼인 상태의 결측치: `0개`
  - 별도 결측치 대치 미수행
- 완전 중복 24행
  - 중복 제거 후 본 분석 수행
  - 중복 유지 `+0.176점`, 제거 `+0.174점`으로 비보정 결과 변화가 거의 없음
- `fnlwgt` 가중 민감도
  - 가중 평균 차이: `+0.172점`
  - 비가중 결과와 방향·크기가 유사하지만 본 분석은 비가중 결과로 정의
- IQR 후보
  - 나이 `79세 이상`: `142명`
  - `education-num 1~4`: `1,193명`
  - 실제 고령 응답과 낮은 교육수준 범주이므로 오류로 판단하지 않고 유지
  - 유효값 제거 시 특정 집단을 제외해 분석 대상을 바꿀 수 있음
- 미적용 전처리
  - `education-num` 로그 변환: 코드의 교육적 의미가 불명확해질 수 있어 미적용
  - `education-num` 구간화: 이미 순서가 부여된 이산형 코드이며 추가 정보 손실을 피하기 위해 미적용
- 검정 방법 선택
  - 집단별 표본 수와 분산이 달라 Student t-test 대신 Welch t-test 사용
  - p-value뿐 아니라 평균·중앙값·신뢰구간·효과크기·분포를 함께 확인

## 4. 단면·순서형 자료의 한계로 인과 해석과 일반화가 제한됨

- 단면자료 사용
  - 한계: 결혼과 교육 중 어떤 사건이 먼저 발생했는지 확인 불가
  - 보완: 결혼 시점과 교육 완료 시점이 포함된 종단자료 활용
- 결혼 경험 집단의 단순 통합
  - 한계: 기혼·이혼·별거·사별 집단의 차이가 가려질 수 있음
  - 보완: 혼인 상태별 세부 분석 및 다중비교 보정
- 제한된 보정변수
  - 한계: 나이·성별 외의 미측정 교란이 남을 수 있음
  - 보완: 이론적 근거에 따라 가족 배경·사회경제적 환경 등 추가 검토
- 연령 효과를 전체에서 동일하게 가정
  - 한계: 연령대마다 결혼 경험과 교육수준의 관계가 다를 수 있음
  - 보완: 결혼 경험×나이 상호작용 또는 연령대별 분석
- 교육수준 측정의 제한
  - 한계: `education-num`은 실제 교육기간이 아니며 코드 간 간격이 같다고 보장하기 어려움
  - 한계: Welch t-test와 OLS는 순서형 코드를 연속형처럼 취급함
  - 보완: 실제 교육연수·최종 학력·교육 완료 시점이 포함된 자료 사용
  - 보완: 원래 `education` 범주의 분포와 순서형 회귀로 민감도 분석
- 비가중 본 분석
  - 한계: 표본 결과가 모집단 구조를 충분히 반영하지 못할 수 있음
  - 보완: `fnlwgt` 가중 결과를 민감도로 함께 제시하고 조사설계 한계 명시
- 일반화 범위
  - 한계: 1994년 미국 Adult 표본의 결과로 현재 또는 다른 국가를 대표하지 못함
  - 보완: 최신·다국가 자료에서 결과 재검증

## 5. 최종 인사이트

- 통계적 유의성만으로 현실적으로 큰 차이라고 판단하지 않음
- 전처리는 일괄 적용하지 않고 변수의 의미·데이터 범위·분석 목적에 따라 선택
- 비보정 결과와 보정 결과를 함께 제시해 집단 구성의 영향을 구분
- 변수의 측정 수준과 단면자료의 한계를 고려해 연관성과 인과관계를 구분

> **결론:** 결혼 경험과 교육수준 코드 사이의 작은 연관성은 확인됐지만, 이를 실제 교육기간의 차이나 결혼 경험의 인과효과로 해석할 수 없다.
