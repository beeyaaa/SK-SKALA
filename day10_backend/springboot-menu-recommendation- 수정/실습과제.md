# 실습과제 — 메뉴 추천 API 직접 만들기

시작 화면(`http://localhost:8080`)의 **주황색 버튼 4개**는 화면에만 있고 서버에는 아직 API가 없습니다.
지금 누르면 "아직 만들지 않은 API입니다"라는 안내가 나옵니다.

이 버튼들이 동작하도록 직접 코드를 작성하는 것이 이번 과제입니다.

## 작업할 파일

| 파일 | 할 일 |
| --- | --- |
| `src/main/java/com/example/menu/service/MenuService.java` | 추천 로직(메뉴를 고르는 규칙)을 작성 |
| `src/main/java/com/example/menu/controller/MenuController.java` | 버튼이 부르는 주소를 처리할 메서드를 작성 |

화면(`index.html`)도 가급적 수정해서 확장해 주세요....

## 만들어야 할 API

버튼이 부르는 주소는 이미 정해져 있습니다. 이 주소에 맞춰서 만들어 주세요.

| 과제 | 버튼 | 요청 주소 |
| --- | --- | --- |
| ① | 날씨별 추천 | `GET /api/menu/weather/rainy` |
| ② | 기분별 추천 | `GET /api/menu/mood/happy` |
| ③ | 가격대별 추천 | `GET /api/menu/price/search?min=5000&max=10000` |
| ④ | 나만의 추천 | `GET /api/menu/my/solo` |

---

## 과제 ①. 날씨별 추천

`sunny`, `rainy`, `hot`, `cold` 네 가지 날씨에 따라 다른 메뉴를 추천합니다.
정해진 값이 아니면 "추천 가능한 메뉴가 없습니다"를 돌려주세요.

**힌트** — 이미 만들어져 있는 `recommendByCategory`와 `menuByCategory`가 거의 같은 구조입니다.
그 두 메서드를 먼저 읽어 보세요.

**확인** — 주소창에서 `rainy` 자리를 `sunny`, `hot`, `cold`로 바꿔 가며 결과가 달라지는지 보세요.

## 과제 ②. 기분별 추천

`happy`, `sad`, `tired`, `stressed` 네 가지 기분에 따라 메뉴를 추천합니다.
어떤 메뉴를 넣을지는 여러분이 정하세요.

이번에는 **JSON으로** 응답해 봅니다. 이미 만들어져 있는 `MenuResponse`를 사용하세요.
`menuJson` 메서드가 참고 예시입니다.

**확인** — 결과가 문자열이 아니라 `{ ... }` 형태로 나오면 성공입니다.

## 과제 ③. 가격대별 추천

앞의 두 과제와 다른 점이 하나 있습니다. 값을 **두 개**, 그것도 주소 경로가 아니라
`?min=5000&max=10000` 형태로 받습니다.

이럴 때는 `@PathVariable` 대신 **`@RequestParam`** 을 사용합니다. 새로 배우는 부분이니
검색해 보거나 강사에게 물어보세요.

가격 구간은 예를 들어 이렇게 나눌 수 있습니다.

- `max`가 6000 이하 → 저렴한 메뉴
- `max`가 12000 이하 → 보통 가격 메뉴
- 그보다 비싸면 → 특별한 날 메뉴

**생각해 볼 점** — `min`이 `max`보다 큰 값이 들어오면 어떻게 처리해야 할까요?

**주소가 `/menu/price`가 아니라 `/menu/price/search`인 이유** — 기존에 만들어져 있는
`@GetMapping("/menu/{category}")`가 `/menu/한식`, `/menu/price`처럼 **한 칸짜리 주소를 전부**
받아 갑니다. 그래서 `/menu/price`로 만들면 어느 메서드가 처리할지 헷갈리게 됩니다.
주소를 설계할 때는 이렇게 기존 주소와 겹치지 않는지 확인해야 합니다.

## 과제 ④. 나만의 추천

추천 기준을 여러분이 직접 정합니다. 예를 들면,

- 같이 먹는 사람 — 혼밥 / 친구 / 가족
- 남은 시간 — 10분 / 30분 / 넉넉함
- 요일이나 계절

버튼은 `/api/menu/my/solo`를 부르도록 되어 있습니다.
다른 주소를 쓰고 싶으면 `index.html`의 `data-url` 값을 함께 바꿔 주세요.

`MenuService`에 있는 `menus` 리스트를 활용해도 좋고, 새 리스트를 만들어도 좋습니다.

---

## 실행 방법

```bash
./gradlew bootRun
```

브라우저에서 `http://localhost:8080` 으로 접속합니다.

코드를 고친 뒤에는 **앱을 다시 실행**해야 반영됩니다.

## 막혔을 때 확인할 것

- **404가 계속 나온다** — `@GetMapping`에 적은 주소가 버튼의 주소와 정확히 같은지 확인하세요. `MenuController`에는 `@RequestMapping("/api")`가 붙어 있어서 `@GetMapping`에는 `/api`를 빼고 적습니다.
- **500 에러가 난다** — 터미널의 빨간 글씨 중 `Caused by` 부분을 읽어 보세요.
- **`@PathVariable` 관련 에러가 난다** — `@PathVariable("weather") String weather` 처럼 괄호 안에 이름을 함께 적어 주세요.
- **화면이 그대로다** — 브라우저에서 `Cmd+Shift+R`(Windows는 `Ctrl+F5`)로 새로고침해 보세요.
