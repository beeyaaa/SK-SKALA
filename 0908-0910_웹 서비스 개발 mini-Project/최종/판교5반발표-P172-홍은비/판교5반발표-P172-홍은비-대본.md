# DocuFit 발표 대본

판교5반 · P172 · 홍은비 — 5분 · 슬라이드 13장

## 1. 기업대출 제출서류 사전검수 서비스 DocuFit.  

안녕하세요. 판교5반 홍은비입니다. 지금부터 기업대출 서류를 은행에 제출하기 전에 누락과 불일치를 확인하는 B2B 웹 서비스 DocuFit을 소개하겠습니다.

## 2. 목차  

목차는 다음과 같습니다.ㄴ

## 3. 01 기획 배경  

현재 은행권은 생성형 AI를 활용해 여신심사와 심사의견 작성 과정을 자동화하고 있습니다. 
하지만 제가 확인한 공개 사례는 대부분 서류가 정상적으로 접수된 이후의 은행 내부 업무를 지원하는 데 초점이 맞춰져 있었습니다. 
반면 기업 담당자가 접수 전에 하는 서류 점검은 여전히 수작업이라는 점에 주목했습니다.

## 4. 02 Pain Points  

이에 이해관계자별로 Pain Point를 세 가지로 정리해보았습니다. 

첫째, 기업 담당자는 접수 전에 필수서류가 모두 준비됐는지, 유효기간이 지나지 않았는지 확인하기 어렵습니다. 
둘째, 은행 담당자는 여러 문서의 기업명과 사업자등록번호를 반복해서 대조해야 합니다. 
셋째, 보완과 재제출이 반복되면 최신 문서와 이전 문서를 구분하기 어렵습니다. 

이러한 Pain Point를 해결하기 위해 구상한 3가지 방안은 이어서 보여드리겠습니다.

## 5. 03 시스템 액터 정의  

우선 서비스의 액터는 기업 고객 담당자와 은행 기업금융 담당자 두 명 이며 핵심 흐름은 계정 활성화부터 서류 업로드, OCR 자동검증, 보완을 거쳐 은행 확인까지 이어지는 프로세스로 설계했습니다.

## 6. 04 전체 UI 흐름도  

전체 흐름은 기업 담당자의 업로드, 검증, 제출과, 은행 담당자의 검토, 결정 두 시퀀스로 이어집니다. 

## 7. 04 UI 흐름 — 서류 업로드  

먼저 서류 업로드 화면입니다. 
사업자등록증, 납세증명서, 재무제표의 제출 상태와 OCR 처리 상태를 확인할 수 있습니다. 
같은 문서 유형을 다시 올리면 기존 파일을 덮어쓰지 않고 version_no를 증가시켜 이전본을 보존합니다. 
OCR만 실패한 경우에는 파일을 다시 받지 않고 같은 원본으로 최대 세 번 재시도합니다.

## 8. 04 UI 흐름 — 사전검증 결과  

사전검증 결과 화면입니다. 
필수서류 누락, 납세증명서 만료, 기업명과 사업자등록번호 불일치를 확인할 수 있습니다. 
오류마다 대상 문서와 원인, 해결 행동을 함께 주고, 해결 버튼을 누르면 업로드 화면의 해당 문서로 이동합니다. 
미해결 오류가 하나라도 있으면 최종 제출을 차단하고 해결할 목록을 반환합니다.

## 9. 04 UI 흐름 — 은행 상세 검토  

은행 담당자는 상세 검토 화면에서 최신 원본과 OCR 추출값, 검증 결과, 이전 버전을 함께 확인할 수 있습니다. 
보완 요청은 문서 유형 하나를 지정하고, 기업 담당자가 이해할 수 있는 사유를 작성하도록 구성했습니다. 
여러 문서에 보완이 필요하면 문서 유형별로 요청을 등록합니다. 
또한 문서 제출자와 은행 검토자를 각각 기록해 재제출과 검토 과정을 추적할 수 있도록 설계했습니다.

## 10. 05 데이터 모델 설계  

데이터 모델은 화면과 API에서 실제로 사용하는 8개 테이블로 구성했습니다. 
사용자와 대출 신청 사이에서 발생하는 검토 이력은 reviews로 분리해 각각 1대다 관계로 구성되도록 설계했습니다.

## 11. 06 API 명세 정의  

API는 auth, company, review 세 영역, 열한 개로 설계했습니다. 검증 결과를 한 번에 돌려주는 GET validation과, 미해결 오류가 있으면 해결 목록을 반환하는 POST submit가 핵심 api입니다.

## 12. 06 마무리 및 개발 고려사항  

이번 설계에서는 OCR 결과가 항상 정상적으로 생성된다고 가정하지 않고, 실패와 재제출 흐름까지 함께 고려했습니다. 
다만 재업로드한 문서에서도 OCR이 반복적으로 실패할 수 있습니다.
현재 프로토타입에서는 제출을 차단하지만, 실제 서비스로 확장한다면 자동 검수를 중단하고 은행 담당자의 수동 검토로 전환하는 예외 흐름이 필요할 것으로 예상됩니다.
