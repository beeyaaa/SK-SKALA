# 1. 회귀분석 재해석

> 📌 **다루는 것** : 회귀분석의 정의 및 활용 목적 / 딥러닝 적용 위해 필요한 추가 절차

## 1. 회귀방정식이란? — 몸무게로 키 예측하기

**🎯 목적** : 입력받은 몸무게(X)로 **키(Y)를 예측**

| 몸무게 (X) | 키 (Y) |
|-----------|--------|
| 58 | 174 |
| 59 | 175 |
| 60 | 176 |
| … | … |

**회귀식** : $y = ax + b$ → 기울기(a)와 절편(b) = **회귀계수**

### 회귀계수를 구하기 위한 접근 방안 (4단계)

| # | 하는 일 | 예시 |
|---|---------|------|
| **①** | a는 모르는 값이지만 궁극적으로 구해야 할 값 → **일단 임의의 값을 정하여 대입** | a = 1.2, b = 100 |
| **②** | 대입한 임의의 값으로 X=58을 넣어 Y 계산 | y = 1.2 × 58 + 100 = **169.6** |
| **③** | Y의 **실제값과 예측값을 비교** | 실제값 174 – 예측값 169.6 = **차이 4.4** |
| **④** | 실제값과 예측값의 **차이가 0이 되도록 반복** | 0에 가까워지는 a와 b를 구할 수 있음 |

> 💡 이 ①→④ 루프가 바로 **딥러닝 학습 과정 그 자체**입니다. (초기화 → 예측 → 오차 계산 → 업데이트)

---

## 2. 선형모델에서 알고 싶은 것은?

$$\boldsymbol{y = Wx + b} \quad \text{← 가설(Hypothesis)}$$

| 구분 | 기호 | 설명 |
|------|------|------|
| **알고 있는 것** | $x$ | **독립변수 (Feature)** — 모델을 만들기 위해 입력되는 값 |
| | $y$ | **종속변수 (Target)** — 결과값. 모델 예측값과 비교 |
| **알고 싶은 것** | $W$ | **가중치** — 회귀계수 / 기울기 |
| | $b$ | **절편 / Bias** |

> 💡 **핵심**
> - 가중치(W)에 따라 **다양한 기울기 선**이 존재 (y = 2.5x+130, y = 0.517x+144 …)
> - 기울기(W)와 절편(b)은 **파라미터**라 하고, **알고 있는 데이터(x, y)를 학습시켜 결정**됨
> - 딥러닝에서는 최적의 파라미터를 계산하는 대표적 방법이 **경사하강법(Gradient Descent)**

---

## 3. 파라미터 구하는 과정 — 5 Step

### 🅰 선형 회귀분석인 경우

| Step | 내용 | 도구 |
|------|------|------|
| **1. 데이터 정의** | (x, y) 수집 | 몸무게 / 키 |
| **2. 선형 모델 정의 (가설 수립)** | $y = Wx + b$ | 회귀계수·가중치·기울기·절편·Bias |
| **3. 오차 평가, 손실 함수 정의** | $MSE = \frac{1}{n}\sum_{i=1}^{n}(Y_i - \hat{Y_i})^2$ | **MSE** |
| **4. 오차 최소화** | **최소자승법 (Least Squares Method)**<br>$b = \frac{\sum(x_i-\bar{x})(y_i-\bar{y})}{\sum(x_i-\bar{x})^2}$ | 해석적 해(공식) |
| **5. 파라미터 계산** | $y = 2.5x + 29$ | (W, b) 확정 |

### 🅱 딥러닝에 적용하면…!!!

| Step | 내용 | 마음속 대사 |
|------|------|-------------|
| **1. 데이터 정의** | Feature, Target | "데이터는 준비되었고" |
| **2. 선형 모델 정의** | $y = Wx + b$ | "모델 구조 설정했고 **(W, b 초기화)**" |
| **3. 손실 함수 정의** | MSE | "모델을 평가할 기준도 마련했고" |
| **4. 오차 최소화** | **경사하강법 (Gradient Descent)** | "손실함수가 최소가 되는 파라미터를 찾아서" |
| **5. 파라미터 계산** | (W, b) | "모델 학습 통해 **최적화된 파라미터 업데이트**" |

> 🔑 **경사하강법 (Gradient Descent)**
> 손실함수의 **기울기(Gradient)를 낮은 값 쪽으로 이동(하강)**시켜 근사값을 찾는 최적화 알고리즘.
> **손실함수가 최소가 되는 최적의 파라미터를 찾는 과정.**

> ⚠️ **Step 4가 유일한 차이점** — 선형회귀는 **공식(최소자승법)으로 한 방에** 풀고, 딥러닝은 **반복적으로 조금씩 내려가며(경사하강법)** 찾는다.

## 4. Statistics vs Deep Learning — 나란히 비교

| Step | **Linear Regression** | **Deep Learning** |
|------|----------------------|-------------------|
| **1** | 데이터 (x, y) | 데이터 (x, y) — x→Feature, y→Target |
| **2** | 회귀식 정의(가설) $y=Wx+b$ | 분석 모델 정의 $y=Wx+b$ |
| **3** | 평가기준 정의 **(MSE)** | **손실함수 정의** (Loss = $Y - \hat{Y}$) |
| **4** | 예측값 계산 → 잔차 계산 | 예측값 계산 **+ Activation Function** → 잔차 계산 → **Back-propagation** |
| **5** | 파라미터 계산 (최소자승법) | **Optimizer** → Parameter Update (반복 학습, **Epoch**) |
| **완료** | 잔차 ≈ 0 → 최적의 회귀식 | 잔차 ≈ 0 → 최적의 모델 |

### 단계별 상세

| Step | 내용 |
|------|------|
| **Step 1** | 데이터 수집/저장, 학습 데이터셋 정의 (x → Feature, y → Target) |
| **Step 2** | 문제 정의에 따라 Regression or Classification 정의<br>• **[ML]** 평가 기준 : MSE(실제값–예측값), RMSE(√MSE)<br>• **[DL]** 손실함수·비용함수 — Classification이면 **Cross Entropy**<br>→ 손실(오차)을 수치적으로 측정해 **Backpropagation에 필요한 정보 제공** |
| **Step 3** | 학습 모델을 통해 예측값 계산<br>→ 예측값에 **Activation Function을 적용하여 비선형성 추가 (ReLU)** |
| **Step 4** | 잔차(오차, 손실, 비용함수) 계산 → 잔차를 줄이기 위해 **Back-propagation** 진행<br>→ Back-propagation은 **손실이 가장 빠르게 줄어드는 방향**으로, 최적화 알고리즘이 가중치를 어떻게 조정할지 결정 |
| **Step 5** | 파라미터(W, b) 업데이트 → 오차가 최소(잔차≈0)가 되는 최적의 파라미터 계산 (경사하강법)<br>→ 계산된 조정값을 적용하여 가중치 업데이트 (**반복 학습, Epoch**) |

### 🔑 그래서 딥러닝이 추가한 것 3가지

```
[선형 회귀]     y = Wx + b
                     ↓  ① Activation Function 추가 (비선형성)
                     ↓  ② Back-propagation 추가 (오차 역전파)
                     ↓  ③ Optimizer + Epoch 추가 (반복 최적화)
[딥러닝]        위 노드를 Layer로 쌓아 아키텍처 구성
```

## 5. Activation Function (활성함수)

> 🎯 입력 데이터에 **비선형성을 추가**하여 복잡한 패턴과 관계를 학습할 수 있도록 하고, **출력값의 범위를 제한**하여 계산의 안정성을 보장

**노드 하나의 구조**

$$f(x) = \sum_{i=1}^{n} x_i w_i + b \quad \xrightarrow{\ \text{Activation}\ } \quad \hat{y}$$

> 💡 **선형 회귀식을 비선형으로 만드는 활성함수를 가진 노드를 레이어로 쌓아 딥러닝 아키텍처로 구성**

### 3대 활성함수 비교

| | **Sigmoid** | **Tanh** | **ReLU** |
|---|-------------|----------|----------|
| **정의** | $\sigma(x)=\dfrac{1}{1+e^{-x}}$ | $\tanh(x)=\dfrac{e^x-e^{-x}}{e^x+e^{-x}}$ | $ReLU(x)=\max(0,x)$ |
| **출력 범위** | **(0, 1)** | **(-1, 1)** | **(0, ∞)** |
| **특징** | 0~1로 제한되어 **확률값 출력에 유용**<br>⚠️ 입력이 극단적이면 출력이 0 또는 1에 가까워져 **Gradient Vanishing 발생** | -1~1로 제한<br>Sigmoid와 유사하지만 출력이 **0 중심으로 분포** → Gradient Vanishing이 **덜** 발생 | 양수는 그대로, 음수는 0<br>계산이 간단하고 **Gradient Vanishing 문제 적음**<br>⚠️ 일부 뉴런이 죽는 현상 발생 가능 (Dying ReLU) |
| **활용** | Binary Classification<br>Binary Probability (Logistic Regression) | **RNN, LSTM**에서 많이 사용<br>출력이 양수·음수로 나뉘는 문제 | **대부분의 신경망에서 기본**<br>장단점을 보완한 다양한 변형 존재 |

### 🔖 ReLU — '음수 버리기'가 만드는 비선형성

> 입력된 신호에서 **중요한 부분은 그대로 전달**, 필요 없는 **음의 값은 0으로** 만들어서 효율적으로 학습할 수 있도록
> → 신경망이 다양한 특성과 패턴을 인식하고 정확하게 예측/분류하는 데 **필수**

# 2. 모델 최적화

> 📌 **다루는 것** : Gradient Descent 개념 이해 / Forward & Backward Propagation

## 1. Approach — 최적화란?

### 일반적 의미의 최적화 (最適化, Optimization)
- 주어진 조건이나 제약 내에서 **최상의 결과를 얻도록** 과정이나 방법을 조정·개선하는 과정
- **자원·시간·비용을 최소화**하거나 **효율성·효과성을 최대화**하는 것이 주된 목표
- (예) 경제학의 자원 배분, 공학의 설계 최적화, 물류의 경로 최적화

### 머신러닝 모델링에서의 최적화
학습 과정에서 성능 지표를 개선하기 위해 **파라미터를 조정**하여 최상의 성능을 얻는 과정

| 목표 | 내용 |
|------|------|
| **성능 향상** | 모델이 정확하게 예측하고 좋은 성능을 발휘하도록 조정 |
| **일반화 향상** | 새로운 데이터에 대해 잘 작동할 수 있도록 모델 개선 |
| **효율성 증가** | 학습 속도를 높이고, 계산 자원을 효율적으로 사용 |

### 딥러닝 모델에서의 수학적 접근
> 특정 함수의 값을 **최소화 또는 최대화**시키는 최적의 파라미터 조합을 찾는 문제
> → **실제값과 예측값의 차이가 최소(Minimization)가 되는 방향**으로 최적화 수행 = **Loss Function**

---

## 2. DL 최적화 전체 흐름

> DL 모델 최적화는 **Loss Function을 최소화하는 파라미터를 구하는 과정**으로, 경사하강법을 주로 사용

```
                    ┌──────────── Epoch (반복) ────────────┐
                    │                                      │
데이터 (x,y) → 모델 정의 → 예측값 계산 → 잔차(손실) 계산 → Optimizer → Parameter Update
              y=Wx+b    (Activation)    Loss=Y-Ŷ      (SGD, Adam)
              └──────── Forward Propagation ────────┘  └── Back Propagation ──┘


   X1 ─┐
   X2 ─┼──► [Hidden Layer] ──► [Output Layer] ──► Ŷ  ──vs──  Y  ──► LOSS
   X3 ─┘         ▲                                                    │
                 └──────────── Weight Update ◄───────────────────────┘
```

---

## 3. Gradient Descent (경사하강법)

- **Optimizer의 초기 버전**
- 함수의 **기울기(= 경사, Gradient)를 이용**하여 X값을 어디로 옮겼을 때 함수가 **최소값**을 가지는지 알아내는 방법

### 🏔 [참고] 산에서 내려오는 길 찾기 비유

| 개념 | 비유 |
|------|------|
| **Gradient Descent** | **산길 내려가기** — "산 꼭대기(초기 가중치)"에서 출발해 "산 아래(최적점)"로 내려감. **경사면(기울기)을 보고 방향을 결정** |
| **Learning Rate** | **한 걸음에 내려가는 거리** — 한 번에 얼마나 큰 걸음으로 내려갈지<br>• **작음** : 아주 조심스럽게 한 발씩 (아장아장) → **너무 오래 걸림**<br>• **큼** : 두세 발자국씩 뛰어서 → **너무 멀리 뛰어 길을 벗어남** (Over-shooting) |

### ⚠️ Gradient Descent의 한계

> 🗣 **가장 가파른 방향만 따라 내려가면 언젠가는 계곡에 도착하겠지만, 그 계곡이 진짜 우리가 도달해야 할 곳인가?**

| 항목 | 내용 |
|------|------|
| **목적** | 가장 낮은 곳(최소 손실값)을 찾는 것 |
| **특징** | **지역 정보만 사용**하여 산길 내려가기 |
| **한계점** | • **Local Minimum**에 빠질 수 있음 (중간 계곡)<br>• 경사면이 완만하면 **느려짐**<br>• **출발 위치에 민감**<br>→ **항상 정답으로 가는 것은 아님** |

## 4. Learning Rate (학습률)

$$^*W_t = W_t - \eta \cdot \frac{\partial E}{\partial W_t}$$

| 기호 | 이름 | 산길 비유 |
|------|------|-----------|
| $W_t$ | 현재 가중치 | 현재 위치 |
| $\eta$ | **학습률 (Learning Rate)** | 한 걸음에 내려갈 거리 |
| $\frac{\partial E}{\partial W_t}$ | **기울기 (Gradient)** | 경사면의 경사 — 얼마나 가파른지, 어느 방향인지 |
| $^*W_t$ | 새로운 가중치 | 한 걸음 내려간 다음 위치 |

### 학습률 설정 가이드

| 항목 | 내용 |
|------|------|
| **성격** | 0과 1 사이의 값. **사람이 직접 설정 (Hyper-parameter)** |
| **작을수록** | 촘촘하게 파라미터를 변화시킴 → **학습시간 오래 걸림** |
| **클수록** | 손실함수 그래프 자체를 벗어나는 경우 발생 → **Over-shooting** |
| **적정 학습률** | **10⁻⁵ 비율로 시작**, Hyper-parameter Tuning 통해 최적화<br>학습 초기에는 **큰 스텝**으로 빠르게 탐색 → Global Minimum에 가까워질수록 **스텝을 작게** 조정하여 정밀 탐색 |
| **기울기의 의미** | 손실함수(E)의 가중치($W_t$)에 대한 **변화율**. 현재 가중치에서 손실함수가 얼마나 빠르게 변하고 있는지 **방향과 크기**를 포함한 정보 |

## 5. Forward vs Backward Propagation — 숫자로 따라가기

### 🅰 FORWARD (순전파)

**설정** : Input = [2, 3], Actual = [1]

```
X1(2) ──W1(0.11)──┐
                  ├──► H1 (0.85) ──W5(0.14)──┐
X2(3) ──W3(0.21)──┘                          ├──► O (0.191)
X1(2) ──W2(0.12)──┐                          │
                  ├──► H2 (0.48) ──W6(0.15)──┘
X2(3) ──W4(0.08)──┘
```

| 계산 | 결과 |
|------|------|
| $H_1 = 2 \times 0.11 + 3 \times 0.21$ | **0.85** |
| $H_2 = 2 \times 0.12 + 3 \times 0.08$ | **0.48** |
| $O = 0.85 \times 0.14 + 0.48 \times 0.15$ | **0.191** |

**LOSS 계산**

$$Error = \frac{1}{2}(prediction - actual)^2 = \frac{1}{2}(0.191 - 1.0)^2 = \boldsymbol{0.327}$$

> ℹ️ **왜 ½을 붙이나?**
> - 에러는 항상 **양수**여야 함 (그래서 제곱)
> - **제곱함수의 미분에서 상수를 간단하게** 만들기 위해 ½ 추가 (미분하면 2가 나와서 상쇄됨)

### 🅱 BACKWARD (역전파) — W6 업데이트하기

**역방향 논리 전개**
```
prediction = O
prediction = H1·W5 + H2·W6      단,  H1 = X1·W1 + X2·W3
                                     H2 = X1·W2 + X2·W4
prediction = (X1·W1 + X2·W3)·W5 + (X1·W2 + X2·W4)·W6
```

**목표** : $^*W_6 = W_6 - \eta \cdot \frac{\partial E}{\partial W_6}$ 를 계산하기

### 📐 Backpropagation 6단계

| # | 단계 | 수식 | 설명 |
|---|------|------|------|
| **1** | **가중치 업데이트 수식** | $^*W_6 = W_6 - \eta \cdot \frac{\partial E}{\partial W_6}$ | $\frac{\partial E}{\partial W_6}$(기울기) = **오차를 줄이기 위해 얼마나 가중치를 조정해야 하는지** |
| **2** | **Chain Rule 적용** | $\frac{\partial E}{\partial W_6} = \frac{\partial Error}{\partial prediction} \cdot \frac{\partial prediction}{\partial W_6}$ | 오차(E)는 예측값에 따라 달라지므로, **오차를 예측값에 대해 미분하고 → 예측값을 다시 가중치에 대해 미분** |
| **3** | **오차 함수 미분** | $\frac{\partial}{\partial p}\left[\frac{1}{2}(p-a)^2\right] = (p - a)$ | 오차 함수는 **예측값과 실제값 차이의 제곱**으로 정의. 미분하면 **예측오차** |
| **4** | **예측값에 대한 미분** | $\frac{\partial}{\partial W_6}\left[(X_1W_1+X_2W_3)W_5 + (X_1W_2+X_2W_4)W_6\right] = X_1W_2 + X_2W_4$ | 첫 번째 항은 $W_6$와 무관하여 **사라지고**, 두 번째 항만 남음 |
| **5** | **미분 결과 결합** | $\frac{\partial E}{\partial W_6} = (prediction - actual)\cdot(X_1W_2+X_2W_4)$ | 3번과 4번 결과를 곱함 |
| **6** | **수식 정리** | $\frac{\partial E}{\partial W_6} = \Delta \cdot H_2 = \boldsymbol{\Delta H_2}$ | $(p-a)$ = 오차(**delta**)<br>$X_1W_2+X_2W_4$ = **$H_2$** (히든 레이어의 출력) |

> 🔑 **결론** : **기울기 = 오차(Δ) × 그 가중치로 들어온 입력(H₂)**
> - Hidden Layer $H_2$의 출력 오차는 가중치 $W_6$ 업데이트를 요구함
> - 단계별 Backpropagation = 학습 과정에서 **오차가 어떻게 전파/업데이트 되는지** 확인
> - **가중치 업데이트가 모델 성능 개선에 핵심!!**

### 🏔 [참고] Backpropagation 쉽게 이해하기

> 🗣 **출발해서 내려가는 것만 중요한 게 아니라, 내려가다 잘못됐으면 올라가서 수정해야 진짜 좋은 길을 찾을 수 있다!!**

| 단계 | 설명 | 비유 |
|------|------|------|
| **오차 계산** | 실제값 – 예측값 비교해서 오차 계산 | 산 아래 도착했는데 목표랑 다름 |
| **오차 전파** | 오차가 어디서부터 발생했는지 **거꾸로 따라 올라감** | 길을 되짚어 올라가기 시작! |
| **기울기 계산** | 각 지점(가중치)에서 **방향과 조절 정도** 확인 | 돌이 많아서 느려진 건지, 길이 꼬인 건지 파악 |
| **가중치 업데이트** | 계산한 기울기(방향) 따라 **조금씩 수정** | 다시 내려갈 때 더 좋은 길로! |

```
Backpropagation
 ① 내려가면서 길 찾기 (Gradient Descent)
 ② 잘못된 길 찾으면 되짚어 올라가기 (오차 역전파)
 ③ 올라가면서 틀린 지점(가중치) 수정하기
```

## 6. Optimizer — Adam

> 🎯 Adam은 SGD와 비슷하게 기울기를 업데이트하지만, **각 파라미터마다 다른 학습률을 자동으로 저장**하는 알고리즘

$$\boxed{\textbf{Adam} = \text{방향 기억(Momentum)} + \text{상황별 보폭 조절(Adagrad/RMSProp)}}$$

→ **더 빠르고 흔들림 없이 Global Minimum으로 수렴**

### 가중치 업데이트 수식 다시 보기 — 보폭 vs 방향

$$^*W_t = W_t - \underbrace{\eta}_{\textbf{보폭}} \cdot \underbrace{\frac{\partial E}{\partial W_t}}_{\textbf{방향}}$$

| 개선 축 | 아이디어 |
|---------|----------|
| **보폭 (학습률)** | • 보폭은 **상황에 맞게**<br>• **자주 가본 방향은 보폭을 줄임** → Adagrad/RMSProp |
| **방향 (기울기)** | • 방향을 **더 똑똑하게**<br>• **이전에 가던 방향을 기억** → Momentum |

### 🏔 [참고] Adam 쉽게 이해하기

> 산을 내려갈 때, **이전 경험을 기억하면서 더 똑똑하게 걷는 방법**

- **Gradient Descent** : 단순하게 **현재 경사(기울기)만** 보고 내려감 (등산객이 현재 위치의 경사만 보고 움직임)
- **Adam** : 내려가면서 생긴 **피로도와 이전 경로의 방향성까지** 고려해서 더 빠르게, 덜 흔들리며 내려감 → **지형이 울퉁불퉁해도 효과적!**
  - 지금까지 어느 쪽으로 가고 있었나 → **방향 기억** = 기울기 **평균** (이전 방향들의 누적)
  - 이 방향이 얼마나 들쭉날쭉/가파른가 → **변동 크기** = 기울기 **제곱의 평균**

```
Adam Optimizer 흐름
 ① 현재 기울기 계산  : 지금 발 밑이 얼마나 가파른지 확인
 ② 1차 계산 (방향)   : 지금까지 내려온 길을 종합해 속도/방향 정하기
 ③ 2차 계산 (변동)   : 돌부리가 많았는지, 울퉁불퉁 했는지 누적으로 기록
 ④ 업데이트          : 넘어지지 않도록 균형 잡으면서 빠르게 내려가기
```

> 📚 참고 자료 : Alec Radford's animations for optimization algorithms (2015) — 좌측은 error surface에서 minibatch 궤적, 우측은 **saddle point 주변에서의 거동**
> 📄 논문 : *ADAM: A Method For Stochastic Optimization*

## 7. Gradient Vanishing & Exploding

> Backpropagation 과정에서 **기울기 크기가 너무 작아지거나 너무 커지면서** 학습이 제대로 이루어지지 않는 현상

| | **Gradient Vanishing (소실)** | **Gradient Exploding (폭발)** |
|---|-------------------------------|-------------------------------|
| **현상** | Gradient가 레이어를 거칠수록 점점 **작아짐**<br>→ 신경망의 **초기 레이어들이 거의 학습되지 않음**<br>→ 전체 모델 성능 하락 | Gradient가 레이어를 거칠수록 지나치게 **커짐**<br>→ 가중치 업데이트가 너무 크게 일어남<br>→ 최적값에 수렴하지 못하고 **발산** |
| **발생 원인** | **Sigmoid, Tanh** 함수에서 주로 발생<br>미분값이 0에 가까운 경우가 많아, 역전파에서 **계속 곱해지면 점점 작아짐**<br>→ 마지막엔 거의 **0에 수렴** → 학습 멈춤 | 주로 신경망이 **매우 깊거나 초기화가 잘못**된 경우<br>특정 레이어에서 기울기가 큰 값을 가지면 역전파 과정에서 **더 커져 폭발** |
| **해결 방법** | **ReLU** — 양수 영역에서 기울기가 일정<br>**Batch Normalization** | **Gradient Clipping** — 기울기가 일정값(임계값) 이상 커지지 않도록 제한 |

### 📊 [참고] Gradient 관련 용어 총정리

| | **Gradient Descent** | **Learning Rate** | **Gradient Vanishing** | **Gradient Clipping** | **Gradient Decay** |
|---|---|---|---|---|---|
| **대상** | 모델의 가중치 업데이트 방법 | 가중치 업데이트 **속도** | 기울기(Gradient) | 기울기(Gradient) | **가중치**(Weight) |
| **목적** | 손실함수의 기울기 따라 가중치 업데이트 | 학습속도 조절, 기울기 크기에 따라 변화량 조절 | (문제 현상) 신경망이 깊을 때 기울기가 사라져 학습이 멈추는 현상 | 기울기 폭발 방지, 학습 안정성 유지 | **과적합 방지**, 일반화 성능 향상 |
| **작동 방식** | 기울기를 계산하여 가중치를 **반대 방향**으로 업데이트 | 학습률(Hyper-parameter)에 따라 변화량 결정 | 역전파에서 기울기가 점차 작아져 레이어에 도달 전 사라짐 | 기울기가 설정된 **임계값을 넘으면 그 값으로 제한** | 손실함수에 **가중치 크기에 대한 패널티** 추가 |
| **장점** | 단순한 원리로 가중치 최적화 | 수렴 가능하게 함 (Global Minimum) | (학습이 진행되지 않는 현상 설명) | 학습 안정성 보장, 폭발 방지 | 과적합 방지로 일반화 향상 |
| **단점** | LR 설정에 따라 너무 느리거나 발산 | 잘못 설정되면 **학습 실패 원인** | 기울기가 0에 가까워져 학습이 거의 안 됨 | 너무 작은 임계값이면 **학습속도 느려짐** | 정규화가 너무 크면 **성능 저하** |

### 🏔 등산 비유로 한 번에

| 개념 | 비유 |
|------|------|
| **Gradient Descent** | 손실함수라는 **산을 내려가면서** 최소점을 찾기 위해 경사를 따라 이동 |
| **Learning Rate** | 등산 중 **걸음의 크기**를 적절히 조절 (너무 크면 넘어지거나 목표를 지나침, 너무 작으면 오래 걸림) |
| **Gradient Vanishing** | **짙은 안개**로 길이 보이지 않는 상황 |
| **Gradient Clipping** | 가파른 경사를 **줄로 제한**해 넘어지지 않도록 |
| **Gradient Decay** | **배낭의 무게를 줄여** 가볍게 등산 |

## 8. Dropout

> Hidden Layer의 뉴런을 **무작위로 골라 삭제**하면서 학습 → **골고루 학습**되는 효과

> ⚠️ **[주의] 단계별로 동작이 다르다**
> - **Training 단계** → 삭제할 뉴런을 **무작위로 선택**
> - **Testing 단계** → 학습한 모델의 결과를 확인해야 하므로 **모든 뉴런에 신호를 전달**

# 3. 데이터 구조

> 📌 **다루는 것** : 딥러닝에 적합한 데이터 형태 / Tensor Shape 이해

## 0. Deep Learning Goal — 무엇을, 언제까지, 어떻게 공부시키나

$$y = x_1w_1 + x_2w_2$$

```
공부 시킬 값 (x) ──► [모델] ──► 공부 결과 (ŷ) ──vs── 공부할 값 (정해진 값, Y)
                                              └──► 오차/손실 (채점)
```

### ❓ 무엇을, 언제까지 공부시키지?

| 질문 | 답 |
|------|-----|
| 정답(Y)와 최대한 가까워지도록 가중치를 학습 | → **Gradient Descent** (Loss Function) |
| Overfitting 발생하기 직전까지 학습 | → **Dropout** (학습 중단, early stopping) |

> 💬 슬라이드에서는 이 둘을 묶어 표기하고 있는데, 실제로는 **Dropout**(뉴런 무작위 제거로 과적합 억제)과 **Early Stopping**(검증 손실이 나빠지기 시작하면 학습 중단)은 별개의 기법입니다. 둘 다 "과적합 직전까지만 학습한다"는 **같은 목적**을 가진 서로 다른 수단으로 이해하면 됩니다.

### ❓ 학습 데이터가 큰데 어떻게 하지?

| 질문 | 답 |
|------|-----|
| 작은 셋으로 나누어 학습 시키자 | → **Batch, Mini-batch** (데이터 **잉여성** 기반) |
| 여러 번 하면 데이터 특징을 더욱?! | → **Epoch** (학습 데이터 소진 단위) |

> ℹ️ **잉여성(redundancy)** : input이 바뀌어도 output은 바뀌지 않는다
> → 전체 데이터를 다 보지 않고 일부(batch)만 봐도 비슷한 방향의 기울기를 얻을 수 있다는 근거

---

## 1. Batch — 학습 데이터셋은 어떻게 구성하지?

| Batch Size | 동작 | 가중치 업데이트 횟수 |
|------------|------|---------------------|
| **100** | 100문제를 **한 번에 다 풀고** 정답 비교 | **1번** |
| **10** | **10문제씩** 풀고 정답 비교 | **10번** |

> 💡 **Batch Size가 작을수록 자주 가중치 업데이트! 학습을 더 꼼꼼하게~**

## 2. Epoch — 데이터 특징이 잘 반영되도록 어떻게 학습시키지?

> **Epoch** : 시험문제 1 set을 **몇 번 반복해서 풀까**

```
Batch Size = 10, Epoch = 20
 → 시험문제 1 set × 20번
 → 과거 풀었던 것보다 학습 결과 향상을 기대할 수 있음
```

> ⚠️ 반복 학습 효과. **그러나 과도한 반복은 Overfitting!!**

## 3. Epoch vs Batch vs Mini-Batch 정리

| 용어 | 정의 | 예시 (총 20개 데이터) |
|------|------|----------------------|
| **Epoch** | **전체 데이터셋을 한 번 학습** → 파라미터를 한 번씩 업데이트하는 과정 | 1 epoch에서 20개 모두 사용<br>`num_epochs = 3` → 이 과정을 3번 반복 |
| **Batch** | 학습 시 **한 번에 처리하는 데이터 묶음** | `batch_size = 20` (전체) ~ `batch_size = 1` |
| **Mini-Batch** | Batch 중에서, **batch_size가 전체 데이터보다 작은** 경우 | `batch_size = 5` → 1 epoch당 **4개의 mini-batch**로 학습 |

> ✅ **Mini-Batch의 효과** : **메모리 절약 + 학습 속도 향상 + gradient 안정성 확보**
> (전체 데이터에서 작은 데이터로 나누고, 목적에 맞게 Data Augmentation 적용)

### 💻 PyTorch 코드로 확인

```python
import torch
from torch.utils.data import DataLoader, TensorDataset

# (1) 더미 데이터셋 생성 (총 20개의 샘플, 각 샘플은 2개의 피처)
X = torch.arange(1, 41).reshape(-1, 2).float()   # shape: (20, 2)
y = torch.arange(1, 21).float().reshape(-1, 1)   # shape: (20, 1)

# (2) PyTorch Dataset 구성
dataset = TensorDataset(X, y)

# (3) DataLoader로 Mini-Batch 구성 (batch_size=5이면 mini-batch 4개)
batch_size = 5
loader = DataLoader(dataset, batch_size=batch_size, shuffle=True)

# (4) Epoch 설정
num_epochs = 3

# (5) 학습 루프 시작
for epoch in range(num_epochs):
    print(f"\n Epoch {epoch+1}/{num_epochs}")
    for batch_idx, (features, targets) in enumerate(loader):
        print(f"\n Mini-Batch {batch_idx+1}")
        print(f" - Features:\n{features}")
        print(f" - Targets:\n{targets}")
```

> 📊 **구조 읽기** : 바깥 루프 = **Epoch(3번)**, 안쪽 루프 = **Mini-Batch(4개)** → 총 **12번**의 가중치 업데이트

## 4. Batch Normalization

> ▪ BN은 **각 층의 입력을 정규화**해 학습을 빠르고 안정적으로 만듦
> ▪ **손실 지형(Optimization Landscape)을 매끄럽게 해 기울기를 안정시키는 것**이 핵심

| 기대효과 | 내용 |
|----------|------|
| **Gradient 흐름 개선** | 입력 분포가 안정되면서 **Vanishing 완화** |
| **학습 속도 향상** | **더 큰 학습률(learning rate)** 사용 가능 |
| **학습 안정성 확보** | 각 층의 입력 분포가 일정하게 유지 |
| **Regularization 효과** | **과적합 방지** 효과 |

> 🏔 **[Optimization Landscape, 학습 공간]**
> BN은 공간을 **매끄럽게** 처리해 주어 경사가 지나치게 **요동치거나 평평해지는 문제**를 줄일 수 있음.
> 덕분에 gradient가 안정적으로 수렴하고, **더 큰 학습률에서도** 학습이 수월하게 진행됨
> → 모델은 **빠르고 안정적으로 수렴**할 수 있음

## 6. Tensor (텐서)

### 용어의 이해
- 벡터의 개념을 **확장한 기하학적인 양**
- **두 개 이상의 벡터 조합**으로 구성된 물리량
- 딥러닝은 선형 관계를 넘어 **복잡한 비선형 관계**를 학습해야 하는데, 이를 위해 Tensor는 데이터를 **다차원 공간으로 표현**하여 더 많은 정보를 효율적으로 학습할 수 있도록 함

### 차원별 텐서

| 차원 | 이름 | 설명 | 예시 |
|------|------|------|------|
| **0D** | **Scalar** | 구성인자가 1개인 Vector | `x = 1` |
| **1D** | **Vector** | 1차원 배열, 숫자들이 **일렬로 나열** | `x = [1, 2, 3]` |
| **2D** | **Matrix** | **행과 열**로 구성. 각 행이 데이터 포인트, 각 열이 그 특성 | `x = [[1,2],[3,4]]` |
| **3D** | — | 여러 행렬을 하나의 묶음으로 포함.<br>대표적으로 **컬러 이미지** = `[가로, 세로, 채널]`, 색상은 RGB | `x = [[1,2],[3,4]], [[5,6],[7,8]]` |
| **4D** | — | 여러 3D 텐서를 포함.<br>대표적으로 **동영상 데이터** = `[프레임수, 가로, 세로, 채널]` (3D 텐서들이 **시간 축**을 따라 나열) | 3D 텐서 4개 묶음 |

## 7. Tensor Shape

> ▪ 데이터가 배열로 **어떻게 구성되어 있는지**를 나타내는 정보
> ▪ **각 차원이 얼마나 많은 요소를 포함**하고 있는지를 차례대로 설명하는 방식

| | **1D-Tensor** | **2D-Tensor** | **3D-Tensor** |
|---|---------------|---------------|---------------|
| **축** | 1차원의 길이 | X-Y, 두 축의 크기 | X-Y-Z, 3개 축의 크기 |
| **Shape 형식** | (길이) | (가로 크기, 세로 크기) | (가로 크기, 세로 크기, **채널수**) |
| **예시** | **(640)**<br>길이가 640인 1차원 배열<br>640개의 값 포함 | **(640, 640)**<br>640개의 행과 640개의 열<br>640×640개의 픽셀값 | **(640, 640, 3)**<br>640×640 이미지에서 픽셀당 3개(R,G,B)인 3차원 배열 |

### 🔍 [참고] Tensor Shape 쉽게 읽는 법

> **가장 바깥쪽 대괄호부터 하나씩 안으로 들어가며 개수를 센다**

**예제** : `[[[A], [B], [C]], [[D], [E], [F]]]`

| 순서 | 확인 | 크기 |
|------|------|------|
| 1 | 가장 바깥쪽 대괄호 = **첫 번째 차원** | **2** |
| 2 | 그다음 차원 = **두 번째 차원** | **3** |
| 3 | 그다음 차원 = **세 번째 차원** | **1** |

➔ **Shape : (2, 3, 1)**

**추가 예제**

| 데이터 | 풀이 | Shape |
|--------|------|-------|
| `[A, B, C, D]` | 첫 번째 차원 = 4 | **(4, )** |
| `[[A, B, C], [D, E, F]]` | 첫 번째 = 2, 두 번째 = 3 | **(2, 3)** |

```
[출발] 선형 회귀    y = Wx + b   →  W, b를 어떻게 구하지?
   │
   ├─ 통계 방식 : 최소자승법으로 한 방에 (해석적 해)
   │
   └─ 딥러닝 방식 :
        ① 가설 수립       y = Wx + b  (W, b 임의 초기화)
        ② 비선형성 추가   Activation Function (ReLU / Sigmoid / Tanh)
        ③ 예측            Forward Propagation → Ŷ
        ④ 채점            Loss Function (MSE / Cross Entropy)
        ⑤ 책임 추적       Backpropagation (Chain Rule) → ∂E/∂W = Δ · H
        ⑥ 수정            W ← W − η · ∂E/∂W     (Gradient Descent)
        ⑦ 반복            Epoch × Mini-Batch
              │
              └─ 잘 안 될 때의 처방전
                   • 기울기가 사라짐 (Vanishing)   → ReLU, Batch Normalization
                   • 기울기가 폭발함 (Exploding)   → Gradient Clipping
                   • 너무 느리다 / 흔들린다        → Adam (Momentum + 적응적 학습률)
                   • Local Minimum에 빠짐          → Mini-Batch, Momentum
                   • 과적합                        → Dropout, Gradient Decay, Early Stopping
                   • 데이터가 너무 큼              → Mini-Batch

[입력 형태] Scalar(0D) → Vector(1D) → Matrix(2D) → 컬러이미지(3D) → 동영상(4D)
            Shape = 바깥 대괄호부터 안쪽으로 개수를 센 것
```
