# 자동차보험 예시 약관 RAG 평가 기록

## 1. 비교 조건

- 문서: 실습용 가상 약관 PDF, 제1조~제17조
- 청크: 조항 단위, `chunk_size=400`, `chunk_overlap=40`
- 임베딩: `text-embedding-3-small`
- 벡터 저장소: FAISS
- Top-K: 3
- Baseline: 유사도 검색
- 개선 후보: 벡터 검색 + BM25, 상위 8개씩 순위 융합
- 답변 모델: `gpt-4o-mini`, `temperature=0`

이 표는 모델 답변의 핵심을 요약한 것이다. 완전한 출력 문구와 질문별 검색 문맥은 JSON 기록에서 확인할 수 있다. 검색 적중과 답변 정확성은 별도로 판정했으며, 조항이 검색되었다는 사실만으로 답변이 옳다고 간주하지 않았다.

## 4. 측정 결과

- Baseline Hit@3: **7/9 (77.8%)**
- Hybrid Hit@3: **9/9 (100%)**
- 개선: **+2문항, +22.2%p**. Q1의 제10조와 Q4의 제12조를 추가로 찾았고, 기존 적중 7문항은 유지했다.
- 문서 밖 Q10: 두 방식 모두 근거 부족을 명시했다.

2026-10-02에 실제 OpenAI 임베딩과 답변 모델로 실행했다. `results/baseline.json`과 `results/comparison.json`에 질문별 검색 조항, 문맥, 생성 답변을 저장했다. PDF 원문과 대조한 결과 Hybrid는 답이 있는 9개 질문에 필요한 핵심 내용을 모두 답했다. 다만 Q3의 불필요한 항목 나열, Q6·Q9의 넓은 조항 인용은 답변의 간결성·인용 정확도 문제다. 처음에는 제12조가 검색됐어도 Q4에 답변 보류가 나와, 면책·제외 조항도 답의 근거임을 프롬프트에 명시하고 재실행했다. 이 프롬프트 수정은 두 방식에 동일하게 적용했다.

기존 10문항은 검색 방식과 프롬프트를 조정하는 데 사용한 개발용 질문셋이다. 이 한계를 보완하려고 설정을 고정한 뒤 새 질문 10개로 추가 평가했으며 결과는 5절에 기록했다. 두 평가 모두 17개 조항의 가상 약관 하나를 사용하므로 실제 보험업무 성능으로 일반화할 수 없다.

질문·정답 조항과 생성 답변은 이 작업에서 PDF 원문과 대조했지만, 제출자 본인의 최종 검토는 아직 별도로 기록되지 않았다.

## 6. 검토 기준

Top-3에 필요한 조항이 모두 있으면 검색 적중으로 판정했다. 금액·기간·산식·면책 조건은 PDF의 해당 조항과 대조했다. 인용이 검색 문맥에 존재하더라도 질문의 답에 직접 필요하지 않으면 위 표에 별도 지적했다. Q10은 검색 적중률에서 제외하고 추측하지 않는지만 평가했다.
