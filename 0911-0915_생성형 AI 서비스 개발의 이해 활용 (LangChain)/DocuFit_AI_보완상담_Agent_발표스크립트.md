## 1. 프로젝트 소개 — 약 35초

안녕하세요. 판교5반 P172 홍은비입니다.  
저는 기업대출 서류를 은행에 접수하기 전에 점검하는 B2B 서비스 DocuFit의 일부로, **AI 보완 상담 Agent**를 구현했습니다.

이 Agent는 OCR로 서류의 필드가 추출된 이후, 어느 서류의 어떤 값이 문제인지, 어떤 규정 때문에 보완해야 하는지, 그리고 사용자가 무엇을 해야 하는지를 대화로 안내합니다.

## 2. 구현 범위와 전체 흐름 — 약 40초

**[노트북의 `DocuFit에서 이번 구현이 담당하는 부분` 흐름도 표시]**

전체 흐름은 **서류 업로드, OCR 추출, 오류 검증, 보완 상담, 재제출, 은행 검토** 순서입니다. 이번 프로토타입은 그중 OCR 추출 이후의 **오류 검증과 보완 상담**에 집중했습니다.

제출 서류는 OCR로 필드가 추출되었고, 은행 제출 규정도 검색 가능한 텍스트로 등록되어 있다고 가정했습니다. 따라서 실제 OCR API 연동과 규정 PDF의 텍스트화는 이번 구현 범위에서 제외했습니다. 또한 대출 승인과 신용평가는 판단하지 않습니다.

## 3. 핵심 설계 — 약 1분 10초

**[`Tool Calling 설계`, `모의 OCR 결과`, `서류 검증 Tool`, `제출 규정 RAG` 순서로 스크롤]**

핵심은 **서류 검증과 규정 검색을 서로 다른 Tool로 분리**한 것입니다.

첫 번째 `check_documents` Tool은 현재 신청 건의 모의 OCR 결과를 Python 규칙으로 검증합니다. 현재 데모에서는 필수서류 누락, 사업자등록번호 불일치, 유효기간 만료를 판정합니다. 판정 결과는 재무제표 누락, 납세증명서의 사업자등록번호 불일치, 그리고 납세증명서 만료입니다.

두 번째 `search_submission_rules` Tool은 은행의 제출 규정을 임베딩한 뒤, 사용자 질문과 관련된 규정을 RAG로 검색합니다. `Document`, Text Splitter, OpenAI Embedding, In-memory Vector Store, Retriever를 연결했습니다.

Agent는 사용자가 현재 오류를 물으면 검증 Tool을, 제출 기준을 물으면 RAG Tool을 선택합니다. 오류의 원인과 보완 방법을 함께 물으면 두 Tool을 모두 호출합니다. 이렇게 LLM이 직접 숫자를 비교하거나 규정을 만들지 않고, Tool의 결과를 근거로 설명하도록 구성했습니다.

## 4. Agent와 Memory — 약 40초

**[`Tool Calling Agent와 세션 Memory`, `동적 Tool 선택 확인`, `Memory 확인` 표시]**

Agent는 `create_agent` 방식으로 구성했고, 같은 Tool을 반복 호출하지 않도록 Middleware로 호출 횟수를 제한했습니다.

대화 기억은 `InMemorySaver`와 세션별 `thread_id`로 구현했습니다. 예를 들어 첫 질문에서 만료된 서류가 납세증명서라는 답을 받은 뒤, `그럼 그 서류는 어떻게 보완해야 해?`라고 물어도 납세증명서를 이어서 설명합니다. 두 번째 질문에 문서명이 없어도 올바르게 답한다는 점으로 Memory 작동을 확인했습니다.

## 5. Gradio 시연 — 약 1분 10초

**[Gradio 실행 링크를 열고 아래 질문을 순서대로 클릭]**

이제 Gradio 화면에서 실제 작동을 보여드리겠습니다. 추천 질문은 첫 화면에만 나오는 것이 아니라, 매 답변 이후 현재 결과에 맞게 변경됩니다. 화면 아래에서는 실제로 사용된 Tool과 Memory 작동 여부도 확인할 수 있습니다.

**[질문 1 클릭: `현재 제출한 서류에 어떤 오류가 있어?`]**

첫 질문에서는 `check_documents` Tool이 호출되고, 누락·번호 불일치·만료 오류와 보완 방법을 확인할 수 있습니다.

**[후속 질문 클릭: `왜 이런 오류가 발생했는지 규정과 함께 설명해줘.`]**

다음 질문은 오류의 근거를 묻고 있으므로 규정 검색 Tool을 함께 사용합니다. Agent는 검증 결과와 RAG로 찾은 RULE ID를 연결해 이유와 조치를 설명합니다.

**[후속 질문 클릭: `그중 다시 발급해야 하는 서류가 뭐였지?`]**

마지막 질문에는 납세증명서라는 단어가 없지만, 같은 세션의 이전 대화를 참조해 최신 납세증명서를 재발급해야 한다고 답합니다. 화면의 `Memory 작동`이라는 표시로도 연속 대화가 유지된 것을 확인할 수 있습니다.
